# RUNBOOK

## Запуск

1. Создать файл `.env` на основе `.env.example`.
2. Указать необходимые настройки.
3. Запустить сервис:

```bash
docker compose up --build
```

## Проверка

Открыть:

http://localhost:8000/health

Ожидаемый ответ для версии 1.1.0:

```json
{"status":"ok","version":"1.1.0"}
```

## Обновление

1. Указать новую версию Docker-образа в `compose.yaml`.
2. Загрузить новый образ.
3. Перезапустить контейнер.

Например:

```text
v1.0.0 → v1.1.0
```

После обновления проверить:

http://localhost:8000/health

## Откат

Если новая версия работает неправильно:

```text
v1.1.0 → v1.0.0
```

1. Указать предыдущую версию Docker-образа.
2. Перезапустить контейнер.
3. Проверить `/health`.

## Проверка после rollback

Открыть:

http://localhost:8000/health

Для версии `1.0.0` ожидается:

```json
{"status":"ok"}
```

Сервис должен снова отвечать.
